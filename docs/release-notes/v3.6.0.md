## Everynote for Windows v3.6.0 — 안드로이드 v1.34.0 반영

- 왼쪽 패널: 폭이 좁아도 제목이 사라지지 않도록 헤더 버튼·여백·글자 크기가 자동으로 줄어듭니다(최소 폭 140)
- 패널 제목을 메뉴와 같은 아이콘 + 글자로 통일: ★ 미리보기(즐겨찾기만 볼 때) / 미리보기 / 개요 / 음성 녹음 / 검색 (이모지 제거)
- 문서함의 ＋ 메뉴(파일 가져오기·새 노트 만들기·폴더 만들기)를 탭의 ＋와 같은 ‘문서 추가’ 카드 디자인으로 통일
- 제목 줄의 문서 이름을 누르면 이름 변경 창 대신 **그 자리에서 바로 수정**(Enter 저장, Esc 취소)
- **하단 메뉴 플로팅**: 아래 막대를 화면 위에 떠 있는 알약 모양으로 바꾸고 ⋮⋮ 손잡이로 옮길 수 있음(위치 기억)
- **전체 화면 메뉴 계속 표시**: 전체 화면 도구 모음이 자동으로 숨지 않고 떠 있으며 ⋮⋮로 위치 이동
- 위 두 설정은 ⋮ 메뉴 또는 도구 시트의 ‘읽기 편의’에서 켜고 끕니다

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
