## Everynote for Windows v3.36.0

### 주요 기능
- PDF·EPUB·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- EPUB 리더가 전체 화면 책 읽기로 바뀌었습니다. 평소에는 본문만 보이고, 화면 가운데를 누르면 위쪽(뒤로·목차·설정·필기)과 아래쪽(쪽 번호·진행 슬라이더) 메뉴가 나타납니다. 좌우를 누르거나 ←/→·PageUp/PageDown·마우스 휠로 쪽을 넘깁니다.
- 쪽 크기는 고정되고 글자 크기·줄 간격·여백을 바꾸면 전체 쪽 수가 달라집니다. 읽던 위치는 유지됩니다.
- EPUB 책은 문서함의 ‘EPUB 책’ 항목에 따로 보관되고 읽은 정도가 표시됩니다. 필기용으로 변환한 PDF만 기존 문서함에 저장됩니다.
