## Everynote v3.0.0

**PDF Note for Windows가 Everynote로 이름을 바꾸고, 설치 프로그램과 Google 드라이브 동기화가 추가되었습니다.**

### 새 기능
- **설치 프로그램**(x64 / ARM64): 내 계정 설치(관리자 권한 불필요) 또는 모든 사용자, 시작 메뉴·바탕 화면 바로 가기, 작업 표시줄 고정, 설정 > 앱에서 제거, 한국어/영어. ‘Everynote로 열기’ 연결은 선택 사항이며 기본 앱을 바꾸지 않습니다. 제거해도 문서·설정은 기본으로 남습니다.
- **Google 드라이브 동기화(선택)**: 모바일 앱과 같은 구글 계정으로 동기화. 계정별로 켜고 끄며, 권한은 `drive.file` + 이메일뿐. 로그인 정보는 Windows DPAPI로 암호화되어 저장됩니다.
- **새 아이콘·새 이름 Everynote**: 모바일 앱의 파란 문서+연필을 더 다듬은 아이콘.
- 마우스·터치 사용성: 휠/가장자리 클릭/방향키/드래그 페이지 넘기기, 확대 버튼(＋ / 100% / －)과 ‘페이지 추가’ 버튼, 옆 패널 너비 조절, 배경과 종이 구분.
- 글상자 서식(정렬·글머리표·체크리스트·밑줄), 도형/이미지 크기 조절 핸들과 삭제 버튼, 쓰기 도구 아이콘 표시, **인쇄**.
- 도움말/README에 **오프라인(사내망)에서 제한되는 기능** 정리.

### 설치
아래 파일 중 `Everynote-Setup-v3.0.0-x64.exe`(ARM 노트북은 `-arm64`)를 받아 실행하세요. 설치 없이 쓰려면 `Everynote-v3.0.0-win-x64.exe`(포터블).

### 업그레이드
기존 PDF Note for Windows의 문서·설정(`문서\PDF Note`, `%LOCALAPPDATA%\PDFNote`)은 그대로 사용합니다. 포터블 exe는 삭제해도 됩니다.
