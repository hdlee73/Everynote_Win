## Everynote for Windows v3.19.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 설정 아이콘을 균형 잡힌 톱니바퀴 모양으로 바꿈
- 하단 메뉴의 필기 모드 옆에 지우개 단추 추가(한 번 더 누르면 지울 범위 메뉴)
- 필기 도구 줄을 끌어서 화면 어디로든 옮길 수 있음(위치는 기억됨)
- 굵기 선택과 색 선택을 필기 도구 줄 아래 한 줄로 이동. 펜과 형광펜이 같은 굵기·색 줄을 함께 사용
- 화면 나누기에서도 책장 넘김과 슬라이드 효과가 동작(활성 화면에서만)
- 슬라이드 효과를 이전 페이지가 밀려 나가고 새 페이지가 밀려 들어오는 방식으로 개선
- 오른쪽 화면을 눌렀다가 화면 나누기를 끝내면 두 쪽 보기의 두 페이지 위치가 좌우로 뒤바뀌며 가장자리로 갈라지던 문제 수정
- 페이지 미리보기의 기본 보기를 ‘전체 페이지’로 변경(직접 고른 설정은 유지)
