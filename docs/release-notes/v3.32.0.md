## Everynote for Windows v3.32.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 기기 간 동기화를 문서함 메뉴로 옮겨 문서를 열지 않아도 쓸 수 있음
- 동기화가 문서와 폴더를 비교해 양쪽을 가장 최근 내용으로 맞춤 (방향 자동 제안, 일부만 선택해 동기화 가능, 충돌 표시, 열려 있는 문서도 처리)
- 도구 막대 위쪽의 ⠿ 점 6개를 누른 채 끌어 원하는 가장자리로 옮기기
- 올가미로 고른 개체 복사·잘라내기·삭제
- 문서 추가 메뉴에 폴더 일괄 불러오기 추가 (Android와 메뉴 구성 통일)
