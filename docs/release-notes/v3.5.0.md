## Everynote for Windows v3.5.0 — 안드로이드 v1.33.0 반영

- **기기 동기화(같은 Wi-Fi)**: 도구 → ‘다른 기기와 동기화’. 휴대폰 앱에 표시된 주소·코드를 입력하고 방향(PC → 휴대폰 / 휴대폰 → PC)과 문서를 골라 **PDF·노트·그림·녹음을 통째로 덮어쓰기**
- 자동 동기화·클라우드 없음, 같은 이름의 문서만 덮어쓰고 삭제는 전달하지 않음, 열려 있는 문서는 덮어쓰지 않음
- 평문 HTTP + 6자리 코드, 사설 IP 주소만 연결

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
