## Everynote for Windows v3.10.0 — 안드로이드 v1.38.0 반영

- 전체 화면 도구 모음: 일반 화면의 하단 메뉴처럼 흰 배경에 아이콘 색을 입힘
- 하단 메뉴를 세로(왼쪽·오른쪽 옆, 세로 띄우기)로 둘 때 메뉴와 하위 메뉴가 세로 메뉴를 가리지 않고 옆에 열림. 세로 메뉴의 페이지 번호를 가운데 정렬
- 메인 ⋮ 메뉴: 중복이던 ‘모든 문서 백업·복원’ 항목을 없애고 ‘내보내기·백업’ 안의 ‘모든 문서 백업’ / ‘모든 문서 복원’으로 정리(문서를 열지 않았을 때도 ‘내보내기·백업’에서 사용). 아래에 메뉴가 더 있으면 ‘아래에 더 있음’ 글자 대신 두 줄 V 모양(⌄⌄) 아이콘 표시
- 앱 안에서 재생되지 않던 AVI·WMV 등 동영상: 넣을 때(이미 넣은 동영상은 처음 재생할 때) Windows 내장 기능으로 MP4로 바꿔서 앱 안에서 재생(인터넷 불필요). Windows에 코덱이 없어 바꿀 수 없으면 Windows 동영상 앱으로 열어 줌
- 대화상자 버튼(취소·넣기·만들기·닫기 등)이 가운데에 오도록 정렬하고 디자인을 다듬음. 표 만들기 창을 넓혀 색 동그라미가 타원이 아닌 원으로 보이게 함
- 두 쪽 보기: 두 페이지가 가운데에서 맞닿고, 확대·축소·이동해도 한 장처럼 붙어서 움직임
- 형광펜 메뉴에 투명도 슬라이더와 25%·40%·60%·85% 빠른 버튼 추가(다음에도 기억)
- 지우개를 한 번 더 누르면 지울 범위(5단계 + 세밀 조절) 메뉴. 지우는 동안 범위 원 표시, 범위 안의 필기를 모두 지움
- 글자 선택 > 단어장: 단어를 복사하고 네이버 영영사전을 그 단어로 엶
- 메모(포스트잇) 크기 조절·회전·삭제 손잡이를 마우스로도 사용
