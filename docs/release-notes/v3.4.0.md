## Everynote for Windows v3.4.0 — 안드로이드 v1.31.1 · v1.32.0 반영

- 새 아이콘: 연필과 노트 모양(남색 그라데이션) — 앱·설치 프로그램·작업 표시줄 모두 교체
- 새 노트 서식 목록 맨 위에 **금감원노트**(기본값) · **금감원노트_칸나누기** · **리갈노트** PDF 서식 3종. 서식 목록은 메뉴 카드 디자인, 서식 미리보기 표시
- 삽입한 사진·스티커·도형·표를 선택하면 나오는 메뉴가 메뉴 카드 디자인으로 바뀌고, **투명도 슬라이더**(10~100%)로 바로 조절(JSON `alpha`)
- 스티커에 **마스킹 테이프 16색** 추가(그림 요소로 삽입, 크기·회전 조절 가능, 파일명 `tape-NN.png` — 안드로이드와 호환)
- 글 상자: 글꼴을 **콤보박스**로 선택(고딕 5종·명조·고정폭·타자기·손글씨·캐주얼, 목록에서 글꼴 미리보기), 굵게는 **B**, 기울임은 위아래 막대가 있는 기울어진 **I**
- 메뉴 통일: 넘김 효과·페이지 넘김 설정·삽입·학습·내보내기·문서 추가는 옆으로 펼쳐지는 **캐스케이드 메뉴**, 새 아이콘 24종, 목록형 대화상자(휴지통·내보내기 형식 등)에도 아이콘 추가
- ‘사진·이미지’는 ‘파일에서 선택 / 복사한 이미지 붙여넣기’ 메뉴 카드로 바뀌었고 바깥을 누르면 취소
- 미리보기 패널: 제목을 **🖼️ 미리보기**로 통일하고 🔍 검색 · 🔖 개요 · 🎙️ 음성 녹음 이모지 추가, 페이지·개요·녹음의 ⋮ 메뉴는 패널 오른쪽에 메뉴 카드로 표시, 개요·녹음 항목을 밀어서 삭제할 때 iOS 메일처럼 빨간 삭제 영역과 휴지통 아이콘 표시
- 검색: 찾은 단어만 강조, 패널을 닫으면 확대 비율이 100%로 복귀
- 확대/축소 버튼은 5% 단위
- 노트·발췌 내보내기: Anki 제거, **PDF · Word(.docx)** 추가. ‘주석 백업’은 ‘필기 백업 파일 저장/불러오기’로 이름 변경
- 여백 자르기 기본값을 꺼짐으로 변경(용지 그대로 표시), HWP 두 쪽 나누기 질문과 ‘두 쪽 나눈 사본 만들기’ 제거(안드로이드 v1.31.1과 동일)
- 안드로이드와 같은 저장 형식 유지 — 백업 JSON 호환
- 구글 드라이브 동기화는 제외

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
