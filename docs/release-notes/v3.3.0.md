## Everynote for Windows v3.3.0 — 안드로이드 v1.30.1 · v1.31.0 반영

- 버그 수정: ‘여백 자르기’가 켜져 있을 때 글이 페이지 위쪽에만 있는 쪽(예: 2쪽짜리 PDF의 2쪽)이 다른 쪽보다 훨씬 크게 보이고 아래 여백이 잘리던 문제를 고침 — 세로 방향으로는 페이지의 90% 이상을 항상 보여 주어 모든 쪽이 같은 배율로 표시되고, 짧은 쪽도 아래 빈 공간까지 보임(두 쪽 보기·확대/이동 한계도 그대로 동작)
- 목록형 대화상자(휴지통·보기 방법·정렬·폴더 색상·페이지 넘김 효과·문서 추가 등)를 하단 시트에서 메인 메뉴와 같은 둥근 카드 스타일(왼쪽 정렬 행, 선택 항목 ✓)로 통일
- 더보기 ‘메뉴’와 페이지 메뉴도 아이콘 타일 시트에서 같은 메뉴 카드 스타일로 변경
- 휴지통: ‘휴지통 비우기’ 추가(확인 후 영구 삭제)
- HWP 변환 후 두 쪽 판별을 용지 크기뿐 아니라 본문 배치(좌·우 두 덩어리와 가운데 빈 틈)로도 확인
- 더보기 메뉴에 ‘두 쪽 나눈 사본 만들기’ 추가 — 가로로 넓은 면이 있는 어떤 PDF든 좌·우로 나눈 사본을 문서함에 저장
- 화면 축소: 40%까지 줄일 수 있고 회색 배경 가운데에 표시(＋/－ 버튼, 두 손가락 핀치, Ctrl+휠)
- 안드로이드와 같은 저장 형식 유지 — 백업 JSON 호환
- 구글 드라이브 동기화는 제외

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
