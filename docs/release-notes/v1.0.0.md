## PDF Note for Windows 1.0.0

Android용 [PDF Note](https://github.com/hdlee73/PDF-Note)의 Windows 버전 첫 릴리스입니다. 필기 가능한 노트북(갤럭시 북 플렉스, 서피스 등)과 저사양 PC를 위해 가볍게 만들었습니다.

### 포함 기능
- PDF 읽기: 탭, 최근 문서, 썸네일, 개요(PDF 목차 + 내 개요), 즐겨찾기, 페이지 이동, 검색, 이어 읽기
- 펜 필압 필기 · 형광펜 · 획 지우개 · 올가미 · 실행 취소/다시 · 손가락 필기 켜기/끄기
- 글자 선택 → 하이라이트(+메모) · 복사 · 번역 · 읽어주기 · 사전 · 개요 추가 (스캔본은 Windows OCR)
- 포스트잇 메모, 새 노트(백지/줄/모눈, 페이지 자동 추가)
- 영역 캡처, 주석 포함 PDF 내보내기, Markdown/CSV/Anki 내보내기, 주석 백업·복원
- 절약 모드, 전체 화면, 완전 오프라인

### 받는 파일
- `win-x64.exe` — 대부분의 PC (설치 불필요)
- `win-arm64.exe` — ARM 기기
- `win-x64-lite(...)` — 작은 용량, .NET 8 Desktop Runtime 필요

서명되지 않은 앱이라 SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누르세요.
