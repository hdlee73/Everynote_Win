## PDF Note for Windows 1.0.0

Android용 [PDF Note](https://github.com/hdlee73/PDF-Note) **v1.26.0** 기능을 기준으로 만든 Windows 버전 첫 릴리스입니다. 필기 가능한 노트북(갤럭시 북 플렉스, 서피스 등)과 저사양 PC를 위해 가볍게 만들었습니다.

### 포함 기능
- PDF 읽기: 탭, 문서함(폴더·즐겨찾기·휴지통), 썸네일, 개요, 즐겨찾기 페이지, 검색(▲▼), 이어 읽기, 여백 자동 자르기
- 펜 필압 필기 · 형광펜 · 지우개 · 사각/타원 올가미 · 실행 취소/다시 · 손가락 필기 켜기/끄기
- 글자 선택 → 하이라이트(+메모) · 복사 · 번역 · 읽어주기 · 사전 · 개요 · 링크 걸기 (스캔본은 Windows OCR)
- 삽입: 타이핑(글꼴·크기·색), 이미지, 스티커, 도형, 표, 링크 / 포스트잇 메모(색·크기)
- 음성 녹음(페이지 연결), 새 노트(페이지 삽입·삭제)
- 영역 캡처, 주석 포함 PDF 내보내기, Markdown/CSV/Anki 내보내기, 주석 백업·복원
- 절약 모드, 전체 화면, 화면 켜 둠, 완전 오프라인

### 아직 없는 기능
HWP/Office 자동 변환, 두 쪽 보기·듀얼 뷰, 어두운 문서 배경, 책장/말림 넘김 효과, 동영상 삽입, PDF 페이지 추가·삭제, 공유

### 받는 파일
- `win-x64.exe` — 대부분의 PC (설치 불필요)
- `win-arm64.exe` — ARM 기기
- `win-x64-lite(...)` — 작은 용량, .NET 8 Desktop Runtime 필요

서명되지 않은 앱이라 SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누르세요.
