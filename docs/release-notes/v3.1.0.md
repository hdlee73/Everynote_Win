## Everynote for Windows v3.1.0 — 안드로이드 v1.29.0 반영

- 글상자 서식을 안드로이드와 같은 저장 방식으로 통일(정렬·밑줄·취소선·글머리/번호/체크리스트, Enter로 항목 이어짐) — 백업 JSON 호환
- 사진·스티커·동영상 가로/세로 따로 조절, 오른쪽 위 × 삭제 버튼
- 글자 선택 메뉴가 선택한 글자를 가리지 않도록 배치, 삽입 하위 메뉴
- 펜 메뉴 굵기·종류 아이콘 표시, 번역 결과 포스트잇 바로 붙이기, 단어장(단어 복사)
- 구글 드라이브 동기화는 제외

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
