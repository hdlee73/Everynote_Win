## Everynote for Windows v3.17.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 지우개의 기본 방식이 ‘부분 지우기’로 바뀜(지우개 메뉴에서 ‘획 지우기’를 고르면 그 선택이 유지됨)
- 하단 메뉴 정리: 페이지 이동 · 보기 방법 · 읽기 모드 · 필기 모드 · 타이핑 · 즐겨찾기 · 올가미 · 삽입 · 메뉴 위치. 문서 개요는 페이지 이동 메뉴로 옮겼고, 페이지 이동·보기 방법·삽입은 눌러서 서브메뉴가 열림
- 필기 모드에서 펜·형광펜·지우개·실행 취소·다시 실행 줄이 화면 위에 계속 보이며, 필기 모드 단추를 다시 누르거나 메뉴 위치 메뉴에서 숨기고 다시 보이게 할 수 있음(선택은 기억됨). 메모 추가는 삽입 메뉴 안으로 이동
- 화면 나누기: 활성 화면의 네 변에 굵은 파란 테두리를 그리고, 페이지 넘김 화살표를 그 화면의 양쪽에 표시
