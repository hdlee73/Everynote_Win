## Everynote for Windows v3.24.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 펜 필기 떨림을 크게 줄임: 100% 배율에서 쓴 글씨가 자글자글하던 것을, 화면 픽셀 기준으로 입력을 보정(느리고 미세한 떨림은 강하게, 빠른 획은 거의 그대로)하고 더 촘촘한 지터 제거 후 곡선으로 이어 그림
- 이전 버전에서 쓴 필기도 그릴 때 한 번 더 다듬어 부드럽게 보임
