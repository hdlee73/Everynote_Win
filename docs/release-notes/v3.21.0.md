## Everynote for Windows v3.21.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 펜·형광펜 설정을 한 장의 깔끔한 패널로 정리: 미리보기, 펜 종류, 굵기, 투명도, 색상, 직선·손가락 필기를 한곳에서 조절
- 굵기를 4단계 버튼 대신 1~100 슬라이드로 세밀하게 조절하고, 투명도도 같은 패널에서 바꿈
- 필기 도구 줄 아래 굵기·색 줄을 없애 화면을 가볍게 함(펜·형광펜을 한 번 더 누르면 설정 패널이 열림)
