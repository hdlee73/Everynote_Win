## Everynote for Windows v3.9.0 — 안드로이드 v1.37.0 반영

- 설치 프로그램: 프로그램 설치 폴더와 문서 저장 폴더를 각각 직접 고를 수 있음 (/LIBRARY="D:\노트" 옵션 지원)
- 하단 메뉴: 메뉴 안의 ‘하단 메뉴 플로팅’ 대신 하단 메뉴 오른쪽 끝 아이콘에서 ‘아래 고정 / 화면 위에 띄우기 / 왼쪽·오른쪽 옆 고정’과 가로·세로 방향 선택
- 메인 ⋮ 메뉴: 아래에 더 있으면 ‘▾ 아래에 더 있음’ 표시. 긴 메뉴 이름은 줄임표(…) 대신 두 줄로 표시
- 메뉴 이름 정리: ‘이 문서 필기 백업 저장/불러오기’(현재 문서만) / ‘모든 문서 통째로 백업’·‘백업 파일에서 모든 문서 복원’(문서함 전체)
- 메인 메뉴 순서: 모든 문서 백업·복원 위로, 사용법·오프라인 사용 안내·앱 정보를 한곳에
- 동영상·유튜브 재생 화면 안에 ⏪10초 / 재생·일시정지 / 10초⏩ 버튼 상시 표시
- 유튜브를 끌어다 놓아도 링크로 가져온 것과 같은 메뉴가 나옴 (유튜브 주소가 들어간 링크 요소도 동일)
