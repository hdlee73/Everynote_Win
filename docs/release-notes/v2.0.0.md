## PDF Note for Windows v2.0.0 — 전면 재작성

안드로이드 PDF Note v1.26.0과 디자인·기능을 맞춰 처음부터 다시 만들었습니다.

- 안드로이드와 같은 화면(iOS 스타일), 탭, 문서함, 두 쪽 보기
- 페이지 넘김 애니메이션(종이 말림 / 슬라이드)
- HWP·DOC·DOCX·PPT·PPTX·XLS·XLSX 불러오기
- 펜 필기, 하이라이트, 메모, 삽입(타이핑·이미지·스티커·도형·표·링크), 녹음, 검색/OCR, 학습 패널, 내보내기

**설치:** 아래 exe를 받아 실행 (x64 / ARM64). DOC·PPT·XLS 변환에는 MS Office 또는 LibreOffice가 필요합니다.
