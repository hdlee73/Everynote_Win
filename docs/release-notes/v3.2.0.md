## Everynote for Windows v3.2.0 — 안드로이드 v1.30.0 반영

- 하이라이트 메뉴에 굵기 막대와 모양(직선 / 자유형) 추가 — 자유형은 마우스·펜·손가락으로 원하는 모양대로 칠하며, 겹쳐 그려도 진해지지 않음
- 안드로이드와 같은 저장 키(`thick`, `path`) 사용 — 백업 JSON 호환, 지우개로 자유형 하이라이트도 삭제
- HWP/HWPX 변환 후 가로로 아주 넓은 면에 두 쪽이 나란히 있으면 ‘한 쪽씩 나누어 열기’를 물어보고, 선택 시 가운데에서 좌·우 두 페이지로 분리(텍스트 유지)
- 도움말의 하이라이트 항목을 ‘색·모양·굵기’로 갱신
- 구글 드라이브 동기화는 제외

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
