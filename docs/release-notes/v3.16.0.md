## Everynote for Windows v3.16.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 문서함에서 문서를 선택하면 위쪽에 ‘N개 선택됨’ 줄이 나타나고 이동·공유·삭제·전체 선택(모두 해제)을 한눈에 누를 수 있음. 이름 변경·복사본 만들기·즐겨찾기 추가/해제는 ⋮ 메뉴로 정리
- 새 노트 만들기: 종이를 목록 대신 미리보기 칸에서 바로 고르고, 색상 칸과 레이아웃(세로·가로)을 한 화면에서 선택
- 설정 화면 추가(문서함 왼쪽 아래 톱니 버튼, 더보기 메뉴): 기본 노트 스타일, 화면 켜 둠, 전체 화면 메뉴 계속 표시, 여백 자르기, 검은 문서 배경, 페이지 넘김·넘김 효과, 앱 정보
- ‘기본 노트 스타일’로 정한 종이·색·방향이 새 노트를 만들 때 가장 먼저 선택되어 있음
