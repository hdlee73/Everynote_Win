## Everynote for Windows v3.15.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 화면 나누기: 열려 있는 문서 두 개를 좌우로 나란히 표시(머리글의 ‘화면 나누기’ 버튼, 보기 방법 메뉴). 각 화면은 자기 문서·페이지·확대·필기를 따로 가지며 터치한 화면에 필기됨. 화면 위의 문서 이름을 눌러 문서를 바꾸거나 좌우를 바꾸고 나누기를 끝낼 수 있음(문서가 하나뿐이면 두 번째 문서를 열도록 안내)
- 손바닥 거부: 펜이 가까이 있거나 쓰는 동안(떼고 0.5초까지) 손가락·손바닥 터치는 무시, 필기 중 손바닥이 닿아도 획이 끊기거나 확대·페이지 넘김이 일어나지 않음. 필기 도구 사용 중 손바닥만 한 접촉도 무시
- 필압: 펜의 필압을 점마다 기록해 선 굵기에 반영(마우스는 일정한 굵기)
- 지우개 ‘부분 지우기’: 지우개 원이 닿은 부분만 지워 획을 둘로 나눔(색·굵기·펜 종류·필압 유지). 지우개 메뉴에서 ‘획 지우기 / 부분 지우기’를 고르며 선택은 기억되고, 펜 뒷면 지우개·측면 버튼에도 적용
- 지우개 메뉴에 ‘이 페이지 모두 지우기’ 추가(확인 창 표시, 지운 직후 ‘실행 취소’로 복구)
