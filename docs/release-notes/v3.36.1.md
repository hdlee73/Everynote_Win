## Everynote for Windows v3.36.1

### 주요 기능
- PDF·EPUB·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 한글(HWPX) 문서의 표가 깨지던 문제를 고쳤습니다. 표 칸이 한 줄 높이로 눌려 글자가 겹치거나 쪽 아래로 넘쳐 잘리던 것이 이제 내용에 맞게 늘어나고 여러 쪽으로 나뉩니다. 표 안 그림도 글자와 겹치지 않습니다.
