## Everynote for Windows v3.23.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 펜 필기를 부드럽게: 글씨가 주글주글하거나 곡선에 각이 보이던 것을 곡선 보간(Catmull-Rom)과 필압·굵기 평활화로 고침
- 필기 중 입력 딜레이를 줄임: 펜을 대고 있는 동안에는 쓰고 있는 획만 다시 그리고, 나머지 화면은 한 번 그려 둔 것을 재사용
- 입력 샘플 간격을 더 촘촘하게 받아 빠르게 쓸 때도 획이 끊기거나 각지지 않음
