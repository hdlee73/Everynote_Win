## Everynote for Windows v3.7.0 — 안드로이드 v1.35.0 반영

- 문서 추가 메뉴 통일: 탭의 ＋와 문서함의 메뉴가 같은 카드 디자인으로 열리고, 순서는 새 노트 만들기 → 파일 가져오기 → 저장된 문서 열기(문서함은 폴더 만들기). 탭 ＋ 글자가 원 중앙에 오도록 수정
- 파일 가져오기에서 이미지(PNG·JPG·GIF·WEBP·BMP)도 문서로 가져오기: 사진 비율대로 PDF 한 쪽이 되고, 아주 긴 이미지는 A4 비율로 나뉘어 여러 쪽이 됨
- 페이지 추가는 이제 바로 앞 페이지와 같은 크기·방향·서식으로 추가. ‘다른 형식으로 페이지 추가’에서 다른 종이와 A4 세로·가로 선택 가능
- 하위 메뉴(예: 문서 추가 ▸)가 누른 항목 바로 옆, 같은 높이에 열리고 화면이 좁으면 메뉴 폭이 줄어듦
- 좁은 패널에서 검색 입력칸이 작아지지 않음(검색창이 한 줄을 차지하고 ▲ ▼ ✕가 아래로 내려감)

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
