## Everynote for Windows v3.20.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 화면 나누기를 좌우뿐 아니라 위아래로도 나눌 수 있음
- 화면을 최대 4개까지 나눌 수 있음(2개: 좌우·상하, 3개: 가로·세로·위 1칸+아래 2칸, 4개: 가로·세로·2×2)
- 각 화면 모서리의 문서 이름 메뉴에서 배치 바꾸기·화면 추가·이 화면 닫기·위치 바꾸기
- 화면 사이 경계(가로·세로 모두)를 끌어 크기를 조절하고, 두 번 누르면 같은 크기로 되돌림
- 화면마다 따로 확대·축소하고, 터치한 화면은 파란 외곽선으로 표시하며, 넘김 화살표가 활성 화면 가장자리에 표시됨
