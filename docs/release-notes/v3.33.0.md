## Everynote for Windows v3.33.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 문서함에서 폴더를 선택해 이름 변경 · 잘라내기(이동) · 복사 · 삭제 (폴더 안 문서의 필기·즐겨찾기·폴더 색상도 함께 이동·복사, 문서와 폴더를 함께 선택 가능)
- 다른 프로그램에서 복사한 글자를 Ctrl+V 또는 삽입 메뉴 ‘붙여넣기’로 글상자에 붙여 넣기
- 페이지 관리 › 표지 만들기: 제목·부제목·이름 입력, 8가지 표지 모양과 6가지 색, 미리보기 (이미 만든 표지는 바꾸기)
- 폴더 일괄 불러오기가 이상한 이름의 폴더를 만들던 문제 수정 (드라이브 루트·특수문자·같은 폴더를 다시 불러올 때)
- 표를 고르면 열·행 경계에 나타나는 손잡이를 끌어 셀 크기 조정 (Android와 같은 형식으로 저장되어 동기화됨)
