## Everynote for Windows v3.29.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 상단 바 아래의 빈 회색 줄(문서 탭 줄)을 항상 숨김
- 여러 문서를 하나로 합치기, 문서의 일부 쪽만 뽑아 새 파일로 저장 (문서함 선택 메뉴 · 페이지 관리)
- 폴더째 가져오기: 폴더 안의 문서를 하위 폴더 구조 그대로 문서함에 추가
- 올가미 메뉴 개편: 자유형/사각형 선택, ‘부분 선택된 개체 포함’ 옵션
- 스티커 메모 팝업: 배경 색상(파스텔 4색) 선택과 삭제
- 도형 삽입 팝업을 도형 미리보기가 있는 타일 모양으로 개선
- 표: 둥근 모서리, 잘라내기·복사·붙여넣기·너비 맞춤, 행/열 추가, 표 삭제, 표 스타일, 행×열 ‘표 설정’ 창
- 글상자 핸들을 삼성 노트 방식(이동·삭제·넓히기)으로 변경
