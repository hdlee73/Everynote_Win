## Everynote for Windows v3.27.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 실행 취소·다시 실행이 펜뿐 아니라 글상자·도형·표·사진·메모·하이라이트 등 모든 편집에 적용됨 (읽기 막대에도 버튼 추가)
- 삽입한 개체(글상자·도형·표·사진·스티커·동영상)를 선택해 잘라내기·복사·복제·붙여넣기·삭제 (Ctrl+X/C/D/V)
- 새 필기 도구 ‘테이프’: 글자를 가리고, 탭하면 투명해져 아래 내용을 확인 (크기·색·직선/자유형)
- 책장 넘김 ‘슬라이드’ 효과를 손가락·마우스 드래그에 맞춰 따라오도록 개선
- 폴더 단위 일괄 백업, 다른 기기에서 백업 불러오기
- 새로 만들거나 가져온 문서는 항상 문서함 최상위에 저장
- 문서함이 폴더 트리 보기로 시작하고, 트리 옆에 파일 목록이 나란히 표시됨 (문서함 닫기 버튼 제거, Esc로 닫기)
- 타이핑 메뉴 오른쪽 끝의 확인(✓) 버튼이 잘리던 문제 수정
- 앱 아이콘에서 파란색 배경 제거
