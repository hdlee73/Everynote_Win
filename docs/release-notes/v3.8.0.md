## Everynote for Windows v3.8.0 — 안드로이드 v1.36.0 반영

- 전체 문서 백업·복원: 메뉴 ‘전체 백업·복원’에서 모든 문서와 필기·주석·사진·녹음·동영상을 zip 하나로 저장하고, 복원할 때 ‘추가 복원’(같은 이름은 사본) 또는 ‘덮어쓰기’ 선택. 안드로이드 백업 파일과 서로 복원 가능
- 설치 프로그램: 기존 데이터가 있으면 ‘업데이트(문서·설정 유지, 기본)’ / ‘새로 설치(기존 데이터를 보관 폴더로 이동)’ / ‘새로 설치하고 삭제’ 중 선택. 앱 안 업데이트와 /UPDATE 옵션은 항상 데이터를 유지
- 앱 정보·업데이트: 버전, 만든이(이현덕 with Claude, hdlee73@gmail.com), 업데이트 확인(앱 시작 시 자동 확인 선택, 새 버전 자동 설치 선택). 설치형은 앱 안에서 바로 업데이트
- 동영상·유튜브를 문서 안에서 재생(요소 메뉴 ‘여기서 재생’), 동영상 가져오기 한도 2GB·대표 이미지 실패 시 대체 이미지 사용
- 글 입력 줄간격 조절과 ‘노트 줄에 맞추기’(금감원노트·칸나누기·리갈노트·줄노트 등 줄 간격에 글줄을 맞춤)
- 메인 화면 아이콘 정리: 위쪽 ‘페이지 목록’은 사이드바 아이콘, 아래쪽 ‘보기 방법’은 눈 아이콘(모바일과 동일)
- 미리보기 패널 여백 확대

설치: Everynote-Setup-*.exe(설치형) 또는 Everynote-*.exe(포터블).
