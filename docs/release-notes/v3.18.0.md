## Everynote for Windows v3.18.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 화면 나누기: 두 화면 사이의 경계를 좌우로 끌어 화면 너비를 조절할 수 있음(경계를 두 번 누르면 절반씩, 너비는 기억됨). 각 화면은 자기 확대·축소를 따로 가지며 활성 화면의 확대 단추와 마우스 휠·두 손가락 확대가 그 화면에만 적용됨
