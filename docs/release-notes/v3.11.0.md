## Everynote for Windows v3.11.0 — 안드로이드 v1.39.0 반영

- 두 쪽 보기: 두 페이지 사이의 어두운 구분선(그림자·테두리)을 없앰. 페이지 넘김(드래그·스와이프)은 문서(두 쪽) 위에서 시작할 때만 인식하고 회색 여백에서는 시작되지 않음
- 동영상: 넣을 때 MP4 변환은 ‘형식을 읽지 못할 때’만 하고, 한 번 변환한 동영상은 재생할 때 다시 변환하지 않음. 변환한 뒤에도 재생되지 않으면 Windows 동영상 앱으로 바로 엶. 동영상 파일을 video/mp4 형식으로 내려 주도록 고침
- 시작하면 문서함을 먼저 엶(문서 파일을 직접 눌러 시작하면 그 문서를 엶)
- 하이퍼링크: 파란 박스와 끝 배지를 없애고 얇은 밑줄만 남김. 링크를 만든 뒤 글자 선택 상태도 끝남
- 링크 글자를 마우스로 클릭(또는 터치)하면 바로 연결된 웹·페이지·문서로 이동. 수정·삭제는 링크를 오른쪽 클릭하거나 길게 눌러 나오는 메뉴, 또는 삽입 목록에서 함
- 왼쪽 패널에 ‘삽입 목록’ 탭 추가: 링크·사진·동영상·유튜브·녹음·도형·표·타이핑을 페이지순으로 모아 보여 주고, 눌러서 이동하거나 ⋮ 에서 열기·수정·위치·크기·삭제
- 하단 메뉴와 전체 화면 플로팅 도구 모음이 함께 보이지 않도록 한 쪽만 보이게 정리
