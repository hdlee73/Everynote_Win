## Everynote for Windows v3.28.0

### 이번 업데이트 (안정화 + UI 시안 확정)
- 안정화: 백업 `safeRel`에 Windows 예약어(CON/PRN/AUX/NUL/COM1-9/LPT1-9) 차단, 호스트 `zip.readText/zip.extract` 항목명 검증(`..`, `/` 시작, `\`, `:` 거부) 추가. 복원 경로는 기존처럼 `WritePath`로 강제되어 유지됩니다.
- Android v1.59.0 백업 규칙과 동일 (호환 유지, 기존 백업 파일은 그대로 복원됨).
- UI 시안 확정: 시안A(하단 5탭 정리)와 시안B(문서함 3영역 + 리더 상단 단순화)를 다음 마일스톤 설계 기준으로 확정. 본 릴리스는 코드 전면 개편 없이 안전장치+버전+문서까지 반영합니다.

### 다음 마일스톤 (예정, 미포함)
- 하단바 10개→5개(홈·보기·필기·삽입·도구) + 필기 시에만 플로팅 펜 패널
- 리더 상단 7개→4개(문서함·제목·검색·전체화면), 카드 ⋮에 백업 통합
