## Everynote for Windows v3.13.0 — 안드로이드 v1.41.0 반영

- 문서함에서 문서를 열 때 ‘Everynote · 문서 열기’ 초기 화면이 잠깐 비치던 것을 없앰(문서가 열릴 때까지 숨김)
- 읽어주기: 선택한 발음의 음성이 기기에 없으면 안내문과 함께 Windows 설정의 ‘음성’·‘언어’ 화면을 여는 단추(링크)를 보여 줌
- 전체 화면: 도구 모음이 숨겨지면 아래쪽 가운데에 ⌃ 단추가 남아 누르면 다시 나옴(처음 세 번은 사용법 안내도 표시)
- 메모(포스트잇) 크기를 더 작게 줄일 수 있고, 작아져도 글자가 칸 밖으로 나가지 않음
- 왼쪽 패널: 메모·하이라이트 메모 목록을 개요 탭에서 ‘삽입 목록’ 탭으로 옮김(개요 탭에는 개요만, 녹음은 음성 녹음 탭에만)
- 표: ‘표 만들기’의 ‘셀별 색 지정’과 표 ‘셀 내용 편집’의 ‘셀 색’에서 칸마다 배경색을 칠할 수 있음
