## Everynote for Windows v3.35.0

### 주요 기능
- PDF·EPUB·Office·한글 문서를 열어 읽고, 펜·형광펜·테이프·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 휴대폰과 같은 네트워크(Wi-Fi·핫스팟·USB 테더링)에서 문서 동기화
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- EPUB 책을 열 수 있습니다. 읽기 전용 리더에서 글자 크기·줄 간격·여백·글꼴·배경(흰색/크림/회색/검정)을 바꿀 수 있고, 목차와 읽던 위치 기억을 지원합니다. 이 조절 버튼은 EPUB을 열었을 때만 나타나며 PDF 화면은 그대로입니다.
- 리더의 ‘필기’ 버튼으로 지금 설정 그대로 책을 PDF로 만들어 문서함에 저장하고, 곧바로 필기 화면에서 엽니다. 설정을 바꿔 다시 변환하면 새 PDF가 만들어지며 이미 쓴 필기는 옮겨지지 않습니다.
