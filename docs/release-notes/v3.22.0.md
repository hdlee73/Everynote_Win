## Everynote for Windows v3.22.0

### 주요 기능
- PDF·Office·한글 문서를 열어 읽고, 펜·형광펜·메모·올가미·도형·표로 바로 필기하고 주석 달기
- 여러 문서를 탭으로 열고, 문서함(폴더·노트북)에서 한곳에 보관 · 검색 · 백업 · 복원
- 필압을 반영하는 5가지 펜, 두 쪽 보기, 화면 나누기(최대 4개), 책장 넘김 효과, 번역·낭독·OCR 등 학습 도구
- 이 컴퓨터에서 오프라인으로 동작하며, 새 버전이 나오면 알려 줌

### 이번 업데이트
- 화면을 처음 나눌 때 문서 제목 칩이 겹치던 문제를 고침
- 페이지 미리보기 메뉴에 ‘필기 있는 페이지만’ 보기를 추가(펜·형광펜으로 쓴 페이지만 모아 봄)
- 형광펜과 하이라이트를 분명히 구분: 형광펜은 필기의 일부(직선·자유형, 색·투명도·굵기 조절)이고, 하이라이트는 문장을 따라 긋는 직선(굵기만 조절). 형광펜 획을 눌러도 하이라이트 메뉴는 뜨지 않음
- 하이라이트는 삽입 메뉴에서 켜고, 삽입 목록에서 모든 하이라이트를 찾아볼 수 있음
- 미리보기 패널에서 페이지별 · 문서 전체의 필기와 삽입 항목을 한 번에 지우기(확인 후 실행)
- 펜 종류 아이콘과 예시 곡선을 부드럽게 다듬음
- 필기 색상에서 두 색이 함께 체크되어 보이던 문제를 확인·정리하고, 형광펜 굵기 범위를 크게 넓혀 변화가 뚜렷하게 보임
- 필기 도구 줄을 아래쪽으로 옮겨도 하단 메뉴 위에 머물러 가려지지 않음
- 삽입 메뉴의 ‘메모 추가’를 ‘메모’로 바꾸고 안내 문구도 통일
- 올가미 모양 선택 줄이 필기 도구 줄처럼 떠다니며(끌어서 이동), 올가미 캡처 창을 다른 메뉴와 같은 모양으로 다듬음
