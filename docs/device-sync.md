# 기기 동기화 (같은 Wi-Fi, 사용자 실행형, 최신 내용으로 맞추기)

- 휴대폰(Android): 문서함 ⋮ 메뉴 → ‘다른 기기와 동기화’ → 주소·코드 표시 (창을 닫으면 서버 종료). 문서를 열지 않아도 됩니다.
- PC: 문서함 ⋮ 메뉴 → ‘다른 기기와 동기화’ → 주소·코드 입력 → 문서·폴더 목록이 비교되어 나타납니다.
- 목록의 각 항목은 수정 시각을 비교해 더 최근 쪽에서 오래된 쪽으로 가는 방향(PC → 휴대폰 / 휴대폰 → PC)이 미리 정해집니다. 한쪽에만 있는 문서·폴더는 없는 쪽에 만듭니다. 같은 내용은 건너뜁니다.
- 일부만 맞추려면 항목의 체크를 풀거나 방향을 바꾼 뒤 ‘동기화’를 누릅니다.
- 마지막 동기화 때의 수정 시각을 기기별로 기억해(`sync_state`) 그 뒤에 바뀐 쪽만 보냅니다. 양쪽 모두 바뀌었으면 ‘충돌’로 표시하고 더 최근 쪽을 기본으로 합니다. 시각 차이가 2분 이내면 같은 시각으로 봅니다.
- 문서 단위로 PDF + 노트(sidecar JSON) + 참조된 이미지·녹음·동영상을 통째로 보냅니다. 삭제는 전달하지 않습니다.
- 열려 있는 문서도 동기화됩니다. 보내기 전에는 저장하고, 받아서 덮어쓸 때는 닫았다가 다시 엽니다.
- 평문 HTTP + 6자리 코드(10회 오류 시 잠김), 사설 IPv4만 허용.
- 구조: `web/js/sync.js`(비교·전송 로직) · `host/Bridge.cs net.http`(https 페이지는 http를 직접 못 부르므로 호스트가 요청) · Android `DeviceSync.java`(`/v1/folders`, `/v1/folder` 추가).
- 테스트: `node dev/sync-test.mjs` (SYNC_PORT/SYNC_CODE/SYNC_LIB/SYNC_ASSETS 지정 시 실제 DeviceSync 서버와 통합), `node dev/sync-ui-test.mjs`.
